# The Joke About the Demo

A one-line joke about working with an AI coding agent, written for
developers who pair with an agent every day. The joke is judged on being
about AI coding agents, a surprising punchline, a true observation from
real demos, economy of words, and freshness.

## Run

Requires Node 22+.

```sh
node main.ts
```

This writes the joke (a single line, at most 280 code points) to
`/output/entry.txt`.
